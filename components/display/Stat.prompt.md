One-sentence: A large metric for stat bands — mono numerals with a dimmed suffix and an uppercase mono caption.

```jsx
<Stat value="1965" label="Established" />
<Stat value="5" suffix="states" size="md" />
<Stat value="60" suffix="+" label="years delivering" onDark />
```

`value` is the pre-formatted number; `suffix` renders small and dimmed in the same color as the numeral (no second color inside one figure); `label` is the caption. Sizes `sm` / `md` / `lg`. Use `onDark` on the teal band.
